# АЗС Онлайн Табло

Интерактивная карта всех АЗС России с актуальной информацией о наличии топлива и
очередях, основанная на отчётах пользователей в реальном времени.

## Возможности

- 🗺️ **Карта АЗС РФ** (данные OpenStreetMap) с цветовыми статусами:
  🟢 есть топливо · 🟢 заканчивается · 🟡 большая очередь · 🔴 нет топлива · ⚫ закрыта
- ⛽ **Статусы по видам топлива** — АИ-92, АИ-95, АИ-98, ДТ, Газ
- 📍 **Геолокация** — ближайшие АЗС, сортировка по расстоянию, построение маршрута
- 👥 **Отчёты пользователей** в 1 клик: статус + комментарий + фото
- ⏱️ **Актуальность** — время обновления, подтверждения, пометка «данные устарели»
- 🔔 **Подписки** на АЗС (основа для уведомлений)
- 🔍 **Фильтры** — бренд, тип топлива, статус; поиск по городу/названию
- 📊 **Аналитика** — загруженность регионов, активность по часам

## Стек

- **Backend:** FastAPI + SQLite (лёгкий, для VPS с 1 ГБ RAM)
- **Frontend:** ванильный JS + Leaflet + MarkerCluster (без сборки)
- **Данные:** импорт `amenity=fuel` из OpenStreetMap через Overpass API

## Запуск (локально)

```bash
cd backend
python3 -m venv ../.venv && source ../.venv/bin/activate
pip install -r requirements.txt
# импорт данных АЗС (можно прервать — данные сохраняются по тайлам)
python -m app.osm_import
# запуск
uvicorn app.main:app --host 0.0.0.0 --port 8011
```
Откройте http://localhost:8011

## Импорт данных

`python -m backend.app.osm_import` тайлами обходит территорию РФ и наполняет
таблицу `stations`. Безопасно перезапускать (upsert по `osm_id`).

## Деплой

См. `deploy/` — systemd-сервис, Apache vhost и скрипт `deploy.sh`.

## Структура БД

- `stations` — заправки (osm_id, name, brand, lat/lon, region, fuels)
- `reports` — отчёты пользователей (status, fuel_type, comment, photo, confirms)
- `confirmations` — голоса подтверждения/спора
- `subscriptions` — подписки на АЗС
